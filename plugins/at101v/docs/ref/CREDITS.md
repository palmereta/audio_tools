# Reference photo credits

All files in this folder are third-party photos used as **visual reference only** (for modelling the panel
layout and colours). They are not shipped with the plugin. If any of them is ever redistributed (for example
in the repo, docs site or a screenshot montage), keep the attribution below. CC BY-SA files require derivatives
of **the photo itself** to stay CC BY-SA. Redrawn UI artwork does not count as a derivative.

The license, author and source were checked through the Wikimedia Commons API (`prop=imageinfo&iiprop=extmetadata`)
on 2026-10-16.

## Non-photo references (not in this folder; copyrighted, for reading only)

- Roland SH-101 Owner's Manual (1982). Scan on the Internet Archive:
  https://archive.org/details/synthmanual-roland-sh-101-owners-manual . Page 52 ("Sound Synthesis Memo") is a
  full-panel line drawing and the most accurate source for label text.
- Roland SH-101 Service Notes, first edition, 1 Nov 1982. Scan:
  https://web.archive.org/web/2015/http://fa.utfs.org/diy/rolandsh101/Roland-SH101-Service-Manual.pdf
